# ШІ у проєктуванні міжпредметного навчання

Прототип сайту адаптивного курсу підвищення кваліфікації для педагогів професійного навчання.
Створено як практичну частину магістерської роботи (УДУ імені Михайла Драгоманова, 2026).

**Сайт онлайн:** https://ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/

## Що є на сайті

Сайт працює як навчальний кабінет педагога з п'ятьма вкладками:

- **Мій курс** – ваш маршрут, прогрес, наступний крок і розклад по тижнях.
- **Модулі** – сім модулів (М0–М6). У кожному: зустрічі в Zoom з планом, самостійні завдання і результат модуля. Виконані кроки можна позначати, прогрес зберігається в браузері.
- **Маршрути** – що означають маршрути А, Б і В.
- **Тест** – 12 питань. Сайт рахує бали і визначає маршрут: 0–4 – А, 5–8 – Б, 9–12 – В.
- **Словничок** – прості пояснення термінів із пошуком.

## Структура файлів

```
index.html   – сторінка з вкладками
test.html    – перенаправлення на вкладку «Тест» (щоб працювали старі посилання)
style.css    – оформлення (темна тема, адаптація під телефон)
script.js    – уся логіка і ВЕСЬ текст модулів, маршрутів, тесту і словничка
README.md    – цей опис
```

Усі файли лежать в одній папці (корені репозиторію), без підпапок.

## Як запустити на комп'ютері

1. Завантажте репозиторій: зелена кнопка **Code → Download ZIP**, розпакуйте архів.
2. Відкрийте папку у Visual Studio Code (**File → Open Folder**).
3. Встановіть розширення **Live Server** (Ritwick Dey).
4. Клацніть правою кнопкою на `index.html` → **Open with Live Server**.

Можна й без VS Code: двічі клацнути на `index.html`, і сайт відкриється в браузері.

## Як опублікувати через GitHub Pages

1. У репозиторії відкрийте **Settings → Pages**.
2. У розділі **Build and deployment** оберіть **Source: Deploy from a branch**.
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 хвилини вгорі сторінки Pages з'явиться посилання на сайт. Вставте його замість рядка «Сайт онлайн» на початку цього файлу.

## Як змінити текст

Усі тексти модулів, маршрутів, питань тесту і словничка зібрані на початку файлу `script.js` (масиви `MODULES`, `ROUTES`, `QUESTIONS`, `GLOSSARY`). Змініть текст у лапках і збережіть файл.
